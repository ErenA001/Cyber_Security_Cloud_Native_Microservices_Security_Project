DATA & PRIVACY

Local storage boundaries

LOCAL FIRST
Authentication

Passwords are stored as Argon2 hashes. Browser sessions use signed JWTs in HttpOnly, SameSite cookies.

Monitoring

Security events, scan results, and assessment summaries are stored in the local SQLite data volume.

AI conversations

Chat history is stored locally in SQLite and is scoped to the signed-in username. Prompts sent to NVIDIA are processed by NVIDIA's hosted API.

Secrets

The NVIDIA API key stays in the backend environment. Do not commit .env or include secrets in prompts, logs, or screenshots.
