# Demo media

`cloudguard-ai-overview-demo.mp4` is a short, silent walkthrough assembled from the three supplied application screenshots. It covers the Overview dashboard, the AI analysis-in-progress state, and the completed NVIDIA NIM analyst briefing.

It is not a live screen recording and does not demonstrate every page or workflow. For a complete group presentation, record the Security Lab, Event Log, Settings, image scan/report, and JSON export workflows from the running application.
